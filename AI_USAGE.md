# AI use

AI assistance was used during development to review the existing code, explain implementation choices, and draft or revise code and documentation. The project authors remain responsible for the implementation and its claims.

No AI-generated scientific observations, terrain elevations, mission telemetry, or science targets are included. The bundled test terrain and PDS test fixtures are synthetic software data, not Mars measurements. `public/data/mola-megt44n000hb.json` is a derived grid created from the user-supplied NASA MOLA PDS product by `tools/mola_to_tile.py`; it is real data, downsampled, and attributed in `DATA_SOURCES.md`. See `README.md` for the distinction between source observations, derived products, and illustrative models.
